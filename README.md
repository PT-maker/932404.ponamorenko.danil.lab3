# 932404.ponamorenko.danil.lab3# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

## Цель работы

Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

## Автор

Понаморенко Данил 932404

## Тема

Вариант №15 «Учёный и исследователь» (гипотезы и методы)

## Описание проекта

Страница «О себе» дополнена навигационным меню, карточками гипотез (Flexbox) и дашбордом методов исследования (Grid). Страница адаптивна для десктопов, планшетов и мобильных устройств.

## Структура страницы

- `<header>` - шапка с именем студента, заголовком и бейджем
- `<nav>` - горизонтальное адаптивное меню (Flexbox) со ссылками на разделы
- `<main>` - основной контент страницы
- `<section>` «Навыки» - маркированный список навыков
- `<section>` «Проекты» - нумерованный список из 4 проектов в виде карточек
- `<section>` «Гипотезы исследования» - 3 карточки `<article>` (формулировка и статус), Flexbox
- `<section>` «Методы исследования» - 3 блока `<article>` (иконка, название, описание, `<details>` + `<summary>`), Grid
- `<section>` «Фотография» - изображение с атрибутами src, alt, width, height
- `<section>` «Обратная связь» - форма с полями «Имя», «Email», «Сообщение»
- `<aside>` - блок с эффектом «матового стекла» (backdrop-filter: blur)
- `<footer>` - подвал с копирайтом и годом

## Реализованные требования

**Flexbox**
- Навигационное меню: горизонтальное, с переносом пунктов (`flex-wrap`)
- Карточки гипотез: `display: flex`, в ряд 1 / 2 / 3 в зависимости от ширины экрана

**Grid**
- Дашборд «Методы исследования»: `display: grid`, 1 / 2 / 3 колонки, на планшете и десктопе 2 строки

**Семантика**
- Карточки оформлены тегами `<article>` с заголовками `<h3>`
- Полное описание метода раскрывается через `<details>` + `<summary>`

**Адаптивность**
- Медиа-запросы: планшеты (от 600px) и десктоп (от 900px), мобильные - базовые стили
- Горизонтальная прокрутка отсутствует (`box-sizing: border-box`, `max-width: 100%` у изображения, `width: 100%` у полей формы)

**Контрастность**
- Контрастность текста не менее 4.5:1 (в том числе статусы карточек и подсказки в форме)

**Сохранено из ЛР №2**
- Внешний `style.css`, inline-стиль `opacity: 0.9` у формы, внутренний блок `<style>` для заголовков
- CSS-переменные в `:root`
- Позиционирование `static`, `relative`, `absolute`
- Состояния `:hover`, `:active`, `:focus`, `:visited`
- Эффект «матового стекла» на `<aside>`, свечение карточек при `:hover`, изменение прозрачности при `:active`
